How it works

01 📄

Upload

User submits a PDF or image of their medical report

02 🔍

OCR Extraction

PyPDF2 (PDFs) or Pytesseract (images) extracts raw text

03 🧹

NLP Processing

Text cleaned, lemmatized, stopwords removed, TF-IDF vectorized

04 🤖

SVM Classification

Trained model predicts IBD or Non-IBD

05 ✅

Access Decision

Verified users gain access; others are rejected

Key features

Dual format support

Handles both PDF documents and image files (PNG, JPG) using different extraction methods — pdfplumber for structured PDFs, Pytesseract OCR for scanned images and photos.

Class imbalance handling

The training dataset had unequal class distribution between IBD and Non-IBD reports. SMOTE oversampling was applied during training to prevent the model from being biased toward the majority class.

NLP pipeline

Extracted text is cleaned using regular expressions, tokenized, lemmatized using NLTK WordNetLemmatizer, and converted into numerical features using TF-IDF (unigrams, bigrams, trigrams).

Production deployment

Deployed as a Flask web application on Render with gunicorn for production serving. Tesseract OCR is installed as a system package on the Render instance for image processing.

Built for MyCCAngel

This classifier was built as a real product feature — not an academic exercise. MyCCAngel is an AI-powered healthcare platform for IBD patients where community trust depends on verified membership.

The precision/recall tradeoff had direct product consequences: false rejects turn away real patients; false accepts dilute the community. This shaped how the model was evaluated and deployed.
