Key features

NLP preprocessing pipeline

Raw poem text is cleaned, tokenized using NLTK, lemmatized to reduce words to their base form, and filtered to remove stopwords — creating cleaner input features for the model.

TF-IDF feature extraction

Term Frequency-Inverse Document Frequency vectorization converts cleaned text into numerical features, weighting terms that are distinctive to specific poem genres rather than common across all text.

Multi-class classification

Unlike binary classification, this model must distinguish between multiple genre classes simultaneously — requiring a one-vs-rest or multinomial approach and per-class evaluation metrics.

Per-class evaluation

Model performance is evaluated per genre using precision, recall, and F1-score — identifying which genres are most and least reliably classified and informing potential improvements.
